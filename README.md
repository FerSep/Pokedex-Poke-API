Pokedex con Poke-API

Pokedex sencilla que consume los datos de la PokeAPI(https://pokeapi.co), visualiza informacion basica del pokemon como nombre, estadisticas, imagen, habilidades.
El objetivo demostrar capacidad de cosumir APIs y uso estructuracion con MVC y uso de componentes.

Tecnologias:

1-Html.

2-Css.

3-JavaScript(vanilla).

Caracteristicas:

-Busqueda por nombre del pokemon.

-Busqueda por filtros, gen, tipos, entre otros.

-Mostrar informacion basica(nombre, imagen, habilidades).
